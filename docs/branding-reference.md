# Referência gráfica do cabeçalho

Por solicitação do usuário, somente os ícones de status da conta (`account_info.png`)
e troca de conta (`switch_user.png`) do APK de referência MakroTV foram utilizados.
Fonte indicada: https://github.com/smartmacro77-gif/apps/releases/download/v1.0/MakroTV.XtreamYT.apk

Os bitmaps originais de 192 × 192 pixels ficam em `drawable-nodpi/ic_account_*.png`.
Nenhum código, credencial ou outro recurso do APK foi incorporado ao app.
A disponibilidade pública do APK não implica licença aberta sobre essas imagens;
confirme a autorização para redistribuí-las antes de uma distribuição pública.

A engrenagem original continua no cabeçalho. Os dois ícones abrem, respectivamente,
os painéis Dados da conta e Perfis. A senha nunca aparece no resumo da conta.
