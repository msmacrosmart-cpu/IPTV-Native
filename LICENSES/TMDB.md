# The Movie Database (TMDB)

The optional metadata integration uses the official TMDB API. Users supply their own TMDB API v3 key and are responsible for complying with its terms and use limits.

This product uses the TMDB API but is not endorsed or certified by TMDB.

The TMDB logo in `app/src/main/res/drawable-nodpi/tmdb_logo.png` is a proportionally rasterized copy of TMDB's approved short logo, retrieved from the public mirror at https://github.com/TheoVasile/Movie-List/blob/5d941c30c90b9a7124b407163f8b7ce8d35ffcb1/frontend/Movie%20List/Assets.xcassets/TMDBLogo.imageset/tmdb_logo.svg.
